🐍 Neon Snake

A modern, responsive browser-based Snake Game built using HTML, CSS and JavaScript.

The project combines classic Snake gameplay with a neon-inspired interface, animated visuals, progressive difficulty, persistent high scores and mobile controls.

🎮 Live Demo

Play the game:

https://DiviData02.github.io/Neon-Snake/


✨ Features

- Neon green animated snake
- Glowing red food
- Smooth canvas-based gameplay
- Increasing difficulty
- Score tracking
- High score persistence
- Level system
- Game-over screen
- Pause and resume
- Particle effects
- Keyboard controls
- WASD controls
- Mobile touch controls
- Responsive design
- Animated background
- No external game libraries required

🛠️ Technologies Used

Frontend

- HTML5
- CSS3
- JavaScript
- HTML Canvas API
- Local Storage API

Python

A separate Python implementation demonstrates the core Snake game logic using:

- Python classes
- Lists
- Tuples
- Randomization
- Collision detection
- Object-oriented programming

🎮 Controls

Desktop

| Key | Action |
|-----|--------|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |
| W | Move Up |
| A | Move Left |
| S | Move Down |
| D | Move Right |
| Space | Pause / Resume |

Mobile

Use the on-screen directional buttons.
